Design System Documentation

A calm, intentional, and coherent design system for serious B2C product companies.

Design Philosophy

Calm, Intentional, Coherent, Confident

This design system is built for serious B2C product companies. It avoids flashy, loud, or playful aesthetics in favor of clarity, consistency, and confidence.

  • No gradients, no glassmorphism, no neon colors
  • No animation noise or excessive motion
  • Maximum 4 colors across the entire system
  • Generous whitespace as a design element

Spacing System

Consistent 8px-based scale. Never use random values like 13px or 27px.

XS: 8px
SM: 16px
MD: 24px
LG: 40px
XL: 64px

Global Layout Structure

Every page follows this consistent structure:

  1. Top Bar: Project name (left), Progress indicator (center), Status badge (right)
  2. Context Header: Large serif headline, 1-line subtext, clear purpose
  3. Primary Workspace (70%): Main product interaction area
  4. Secondary Panel (30%): Step explanation, prompt box, action buttons
  5. Proof Footer: Persistent checklist for validation

Interaction Rules

  • Transitions: 150–200ms duration
  • Timing function: ease-in-out
  • No bounce effects
  • No parallax scrolling
  • Subtle, intentional hover states
